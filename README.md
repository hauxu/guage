## 从哪里来

更矩站在一款开源工具的肩膀上：**Tai**，planshit 在 Windows 上做的用时统计程序（MIT 许可）。

它把一个朴素的问题解得干净利落——前台窗口切换一次，就记一次。于是软件用时、网页用时、应用白名单、关联进程、按进程名与 URL 正则过滤、自动分类、睡眠监测、xlsx 与 csv 导出，全都成了可读的报表。这些能力更矩**全部继承，行为保持原样**，没有为了改而改。

更矩想再往前一步：光看见不够，还得管得住；光能用不够，还得可验证。于是这一版在记录之外补上了约束，在可用之外补上了安全边界。

## 这一版做了什么

### 01 每日额度：把「少用点」变成可执行的规则

给任意程序设一个每日额度，默认 60 分钟，按分钟调整。到点有三条收场路线，任你选：

- **只提醒**：弹一次通知，不打断
- **结束进程**：先倒计时，时间走完再关闭程序
- **锁定遮罩**：全屏盖住，除了解锁什么也做不了

遮罩支持自定义密码解锁；可以禁止靠重启绕过；跨天自动重置额度，熬过零点不会白得一次重来。

### 02 休息提醒：把离开屏幕也排进计划

工作与休息循环计时，默认 25 分钟工作、5 分钟休息，可在 1 分钟到 12 小时之间调整。到点以弹窗加托盘通知打断你。

电脑睡眠再唤醒不会被静默跳过：错过的时段会被标记，并补上一次提醒——而不是从计时里悄悄消失。

### 03 安全边界：三道闸门

- **下载**：更新包只允许落在受控路径，路径越界即拒绝
- **访问**：抓站点图标只连页面自身的域名，不跟随指向内网与回环地址的重定向
- **通道**：浏览器扩展与客户端之间用令牌鉴权，令牌失效即断开

解锁密码以带盐的 PBKDF2 派生保存；同时保留对旧格式的验证，老用户升级后不会因为算法换了反而被锁在门外。

### 04 可验证的更新：签名对不上就不装

更新只从本仓库的 Releases 获取。每个发布包附带 SHA-256 与数字签名，客户端下载后先验签、再解压、最后安装。任何一步对不上，更新中止，不会把半成品铺进你的目录。

### 05 工程化：核心能自己跑起来

核心逻辑与界面分层，核心层不依赖界面即可测试。现有 13 组单元测试，覆盖时间限额、休息提醒、时长归集、导出、解压、更新包与签名校验、路径与 URL 与网络校验、密码哈希及其向后兼容。测试项目自带极简断言，不引入第三方框架，一条命令即可跑完。

## 一次统计是怎样发生的

```mermaid
flowchart LR
    A["前台窗口切换"] --> C[("本机数据")]
    B["浏览器标签页"] --> C
    C --> D["今日 / 本周 / 本月 / 自定义区间"]
    C --> E["每日额度 → 提醒 / 结束进程 / 锁定遮罩"]
    C --> F["导出 xlsx / csv"]
```

数据从采集到落盘全在本机完成，中间不经过任何服务器。

## 三分钟上手

1. 到 [Releases](https://github.com/hauxu/guage/releases) 下载最新压缩包，解压到任意目录
2. 双击 `guage.exe` 启动。程序常驻托盘：双击图标打开主界面，右键唤出菜单
3. 首次运行建议以管理员身份启动——否则读不到提权进程，那部分软件不会被计入

卸载只需两步：在设置里关掉开机自启，再删除程序目录。

## 网页用时与浏览器扩展

应用用时开箱即用；网页用时需要安装一次浏览器扩展（Chrome / Edge 通用）：

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角的开发者模式
2. 点击「加载已解压的扩展程序」，指向 `Guage.Chrome` 目录
3. 回到客户端，在「设置 > 常规 > 功能」里打开网页统计；首页右上角出现「已连接」，配置即生效

扩展的安装细节与权限说明见 [Guage.Chrome/README.md](Guage.Chrome/README.md)。

扩展只与本机客户端通信，不上传任何数据。

## 数据与隐私

- 所有记录只存在这台电脑上，存放位置可以在设置里更改
- 没有账号体系，没有云端同步，没有遥测上报
- 只有两种情况会出网：点击检查更新时获取发布信息；开启网页统计后获取站点图标（只连接该页面的域名，不跟随指向内网与回环地址的重定向）
- 收集范围与用途详见 [隐私政策](privacy.txt)

## 常见问题

**某些程序统计不到？**

以管理员身份运行客户端。普通权限读不到提权进程，那些软件不会被计入。

**扩展装好了，首页却没显示「已连接」？**

依次确认三件事：客户端正在运行；「设置 > 常规 > 功能」里的网页统计已打开；加载扩展时选中的是 `Guage.Chrome` 目录本身。

**换电脑或换目录，数据会丢吗？**

记录都在本机。先把数据目录整体复制到新位置，再到设置里把存放位置改过去即可。

**下载的包怎么确认没被动过？**

每个发布包都附带 SHA-256 与签名，客户端安装更新时会自动校验。
