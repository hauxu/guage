## 六、已知限制

1. 运行时计时状态不持久化（重启后回空闲），设置与台账持久化。
2. 提醒为弹窗+托盘气泡，无强制锁屏。
3. 休眠期间按墙钟计时，唤醒补提醒。
4. 自动化验证环境存在窗口位置漂移（第三方窗口管理干扰），交互验证使用实时窗口定位 + UIA 双通道交叉确认，人工使用不受影响。
