## 它能做什么

更矩在后台安静地记录前台窗口的切换与浏览器的标签页，把散落的一天折算成可读的时长；再让你为程序与网站定下每日额度，到点提醒、到点收手。

**记录**

- **应用用时**：按前台窗口统计，精确到每一次切换；支持今日、本周、本月与自定义区间，可分类，也可为每个程序设别名。
- **网页用时**：配合浏览器扩展记录标签页时长，只统计 `http` / `https` 页面，浏览器失焦即结算。

**约束**

- **时长限制**：为程序设定每日额度，到点三选一——仅提醒、倒计时后结束进程、或锁定遮罩；支持密码解锁、禁止重启、跨天重置。
- **休息提醒**：工作与休息循环计时，到点以弹窗与托盘通知打断你。

**回顾**

- **过滤与白名单**：按进程名、URL 或正则排除噪音，也可以只统计白名单里的程序。
- **数据导出**：把记录导出为 xlsx 或 csv，自己归档、自己分析。

## 三分钟上手

1. 到 [Releases](https://github.com/hauxu/guage/releases) 下载最新压缩包，解压到任意目录
2. 双击 `guage.exe` 启动。程序常驻托盘：双击图标打开主界面，右键唤出菜单
3. 首次运行建议以管理员身份启动——否则读不到提权进程，那部分软件不会被计入

卸载只需两步：在设置里关掉开机自启，再删除程序目录。

## 网页用时与浏览器扩展

应用用时开箱即用；网页用时需要安装一次浏览器扩展（Chrome / Edge 通用）：

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角的开发者模式
2. 点击「加载已解压的扩展程序」，指向 `Guage.Chrome` 目录
3. 回到客户端，在「设置 > 常规 > 功能」里打开网页统计；首页右上角出现「已连接」，配置即生效

扩展的安装细节与权限说明见 [Guage.Chrome/README.md](Guage.Chrome/README.md)。

扩展只与本机客户端通信，不上传任何数据。

## 数据与隐私

- 所有记录只存在这台电脑上，存放位置可以在设置里更改
- 没有账号体系，没有云端同步，没有遥测上报
- 只有两种情况会出网：点击检查更新时获取发布信息；开启网页统计后获取站点图标（只连接该页面的域名，不跟随指向内网与回环地址的重定向）
- 收集范围与用途详见 [隐私政策](privacy.txt)

## 常见问题

**某些程序统计不到？**

以管理员身份运行客户端。普通权限读不到提权进程，那些软件不会被计入。

**扩展装好了，首页却没显示「已连接」？**

依次确认三件事：客户端正在运行；「设置 > 常规 > 功能」里的网页统计已打开；加载扩展时选中的是 `Guage.Chrome` 目录本身。

**换电脑或换目录，数据会丢吗？**

记录都在本机。先把数据目录整体复制到新位置，再到设置里把存放位置改过去即可。

**下载的包怎么确认没被动过？**

每个发布包都附带 SHA-256 与签名，客户端安装更新时会自动校验。
