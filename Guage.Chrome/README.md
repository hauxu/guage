# 更矩 网页统计（浏览器扩展）

配合「更矩」客户端记录网页浏览时长。扩展只在你主动开启网页统计时工作，数据只写本机，不上传任何服务器。

## 安装

先启动客户端，在「设置 > 常规 > 功能」里打开网页统计，然后：

1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 开启右上角的开发者模式
3. 点「加载已解压的扩展程序」，选择本目录

装好后，客户端首页右上角会显示绿色「已连接」；同一台电脑装了多个浏览器时显示「已连接 (2)」。

## 做什么

- 记录当前标签页的浏览时长，浏览器失焦时结算
- 向客户端提供页面标题与站点图标，便于归类与显示
- 只统计 `http` / `https` 页面
- 只与本机客户端通信，并用令牌鉴权

## 权限

扩展只申请计时与连接本机客户端所需的最小权限，具体条目以 [manifest.json](manifest.json) 为准。

## 卸载

在 `chrome://extensions` 里移除扩展即可。已产生的统计数据保存在客户端，不会随扩展一起消失。
