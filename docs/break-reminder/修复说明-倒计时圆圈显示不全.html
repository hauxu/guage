休息提醒 · 倒计时圆圈显示不全 — 修复说明

缺陷修复轮交付：根因取证 → 代码修复 → 双配置构建 → 本机运行验证

修复时间 2026-08-12 Debug / Release 均已构建

一、问题现象

用户反馈「休息提醒」页面的倒计时圆圈显示不全：截图中徽章（工作中）与倒计时（00:54）正常显示，但环形进度只剩残缺的彩色弧线，底环几乎不可见，整体观感像是"断掉的圆圈"。

二、根因（像素级取证）

对用户截图做全图网格扫描与环心定位（倒计时文字反推 + Hough 式圆搜索），确认：环本身渲染了，中心约 (228,568)、半径 75，弧线以用户主题色（#8080FF）正常绘制并随时间递减；缺失的是灰色底环。逐点采样显示底环位置像素为 238,238,238（#EDEDED），与页面背景 244~250 几乎同色——对比度仅约 6/255，肉眼不可辨。

对照主题资源定义（UI\Resources\Themes\Light.xaml）：

资源亮色主题值暗色主题值结论
SettingPanelBorderColor（底环画笔）#EDEDED#232323亮色下与白底同色，底环不可见
SettingPanelSpliteLineColor（表盘刻度）#EDEDED#706F6F亮色下表盘刻度环同样不可见
ThemeBrush（进度弧线 / 徽章）主题紫主题色正常渲染（截图证实弧线存在）

结论：并非动态资源解析失败（卡片边框同用该画笔且正常显示），而是底环配色对比度设计缺陷——亮色主题下底环与背景几乎同色，只有进度弧线可见，形成"圆圈显示不全"。

三、修复方案

底环与表盘刻度不再直接依赖主题边框色，改为代码创建画笔 + 亮度兜底规则：

  1. 读取主题边框色，计算亮度 L = 0.299R + 0.587G + 0.114B；
  2. L ≥ 220（亮色主题的 #EDEDED）→ 改用可辨识中性灰 #C9C9CF（与白底对比度约 54/255）；
  3. L ≤ 80（暗色主题过暗）→ 提亮一档 #4A4A52；
  4. 其余情况沿用主题边框色，主题切换时同步刷新。
