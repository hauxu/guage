# 休息提醒 实现说明

给后续维护者看的实现要点，不是变更记录。

## 计时

`Core/Servicers/Instances/BreakReminderServicer.cs`，无 UI 依赖。

- 心跳是 `System.Timers.Timer(1000)`，但**不用累加心跳**：每次 tick 算 `剩余 = 阶段结束墙钟时间 - 现在`，所以长跑不漂移，休眠跨过的时间也算真实时间。
- 状态（Idle/Work/Break、是否运行、是否暂停、是否休眠）全部在 `lock(_syncRoot)` 内读写；事件在计时器线程触发，订阅方自己切 UI 线程。
- 休眠：订阅 `ISleepdiscover.SleepStatusChanged`，休眠中 tick 直接返回；唤醒后若已过期，标记 `_wakeElapsedPending`，下一 tick 完成阶段并在文案与台账里标注「休眠期间到期」。
- 时长兜底 `Math.Max(1, Math.Min(720, minutes))`：0 或负数按 1 分钟，超大按 12 小时。
- 工作与休息都没启用时 `Start` 抛 `InvalidOperationException`，UI 层先拦并提示。

## 表盘

`UI/Controls/BreakReminderDial.cs`，继承 `FrameworkElement`，`OnRender` 自绘。

- 背景矩形必须画（透明填充也要画），否则 WPF 命中测试穿透，点不到。
- 按下捕获鼠标后按角度换算分钟：`round(atan2/6°) % 60`；中心 18% 半径区域不改数值。
- 颜色从主题字典 `TryFindResource` 取；主题切换由页面 code-behind 订阅 `IThemeServicer.OnThemeChanged` 后 `InvalidateVisual()`。
- 数值 DP 带 `AffectsRender | BindsTwoWayByDefault`，0-59 自动夹紧。

## 提醒

`UI/Servicers/BreakReminderNotifierServicer.cs`，应用启动时由 `App.OnStartup` 取一次实例以激活订阅。

- 阶段完成 → `Dispatcher.BeginInvoke` 到 UI 线程 → 托盘气泡 + 置顶小窗（单实例复用，只更新文案）。
- 弹窗 30 秒后取消置顶，60 秒自动关闭，避免长期压在最上层。

## 配色上的坑

`BreakReminderWindow` 是运行时 `new` 出来的独立窗口，XAML 里用 `DynamicResource` 主题键在部分场景解析失败会变黑底。因此该窗口用固定中性配色（白底、深灰字，图标主题色用 `TryFindResource` 取）。要改成跟随主题，先解决运行时窗口的资源解析问题。

## 配置与台账

`Data/AppConfig.json` 新增一节，旧配置缺这一节由 `AppConfig.EnsureBreakReminderDefaults()` 补上：

```json
"BreakReminder": { "IsWorkEnabled": true, "IsBreakEnabled": true, "WorkMinutes": 25, "BreakMinutes": 5 }
```

分钟数 = 小时 × 60 + 表盘分钟。

台账 `Data/BreakReminderRecords.json` 是数组，最多 200 条，超出丢最旧。`Event` 取值 Start / Complete / Finished / Pause / Resume / Reset / Sleep / WakeElapsed。写盘用临时文件 + `File.Replace`，防止写一半崩溃导致整份台账损坏。

## 构建

```bash
MSBuild.exe guage.sln -t:Build -p:Configuration=Debug -p:Platform="Any CPU"
```

源码文件编码 UTF-8；**新增文件建议带 BOM**，否则编译器与 PowerShell 探测编码时容易出歧义。
