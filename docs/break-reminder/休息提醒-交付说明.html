休息提醒（番茄钟）功能交付说明

Guage · WPF · .NET Framework 4.8

在保留原有统计/限制功能与全部页面不变的前提下，左侧导航栏新增「休息提醒」Tab：表盘式时长选择 + 工作/休息循环计时 + 系统提醒 + 配置与台账持久化；v2 完成界面 UI 优化（与整体风格统一 + 苹果风格动画）。本文档汇总功能说明、实现要点与验证结果。

一、功能概览

🕐 表盘时长选择
谷歌时钟风格圆形表盘，60 刻度 + 数字标注，点击/拖动选分钟（0-59）；超过 1 小时用「小时」步进器（0-12），最长 12 小时 59 分。
☑ 两种模式
工作时长+休息时长双勾选 = 工作→休息→工作循环；仅勾选工作时长 = 只在工作结束后提醒一次。另支持仅休息模式。
🔔 阶段提醒
置顶弹窗（区分"该休息了"/"休息结束"文案）+ 托盘系统通知，应用在后台也能收到；休眠唤醒后补提醒并记录。
💾 持久化
设置存 Data\AppConfig.json（BreakReminder 节），提醒台账存 Data\BreakReminderRecords.json（最多 200 条），重启保留。
设计遵循功能主义网格：表盘刻度严格 6° 等分、双色表达（主题色 + 中性色）、数字每 5 分钟标注，与软件现有主题资源（ThemeBrush/StandardTextBrush 等）一致。

一·五、UI 优化（v2）

🎯 布局重构
表盘放大居中（150px）、步进器圆角容器、34px 大号时长数字、标题"番茄钟"徽章、卡片勾选态主题色描边，与整体 UI 视觉语言统一。
🍎 苹果风格动画
页面入场逐卡弹性滑入（stagger 40ms）、表盘弧线平滑过渡（AppleDecelerate）、环形进度平滑转动、阶段切换环/徽章颜色过渡（紫↔苹果绿）、倒计时数字弹性缩放与每秒微脉冲；全部内置减动效降级。

三、使用说明（摘要）

时长设置

  • 表盘选择 0-59 分钟；超过 1 小时用卡片右侧「小时」步进器（− / +），总时长 = 小时 × 60 + 分钟，如 90 分钟 = 1 小时 + 30 分。
  • 设置实时保存；重启后保留。

两种模式

勾选模式行为
工作 + 休息循环模式工作 → 提醒"该休息了" → 自动休息 → 提醒"休息结束" → 回到工作，循环
仅工作仅提醒模式工作结束后提醒一次，不进入休息，计时停止
仅休息仅休息模式从休息阶段开始，结束后提醒一次
都不勾选无法开始红色提示"请至少勾选工作时长或休息时长"

计时控制

  • 开始计时 → 暂停/继续/重置；阶段完成自动切换并提醒。
  • 计时中修改设置会停止计时并提示（保证行为可预期）。
  • 休眠期间按墙钟继续走，唤醒后补提醒并标注"休眠期间到期"。

完整说明见 使用说明-休息提醒.md。
