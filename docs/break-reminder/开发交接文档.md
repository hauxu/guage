# 休息提醒（番茄钟）开发/交接文档

> 交接对象：维护者 / 后续开发者
> 项目：Guage（Windows 应用使用时长统计与限制软件）
> 技术栈：WPF + .NET Framework 4.8 + Microsoft.Extensions.DependencyInjection + Newtonsoft.Json
> 编码约定：源文件 UTF-8（无 BOM）；**新增文件统一使用 UTF-8 带 BOM**，避免编译器编码探测歧义

## 一、功能概述

在保留原功能与页面的前提下，左侧导航栏新增「休息提醒」Tab：

- 工作时长/休息时长设置（谷歌时钟风格圆形表盘选分钟 0-59 + 小时步进器 0-12，最长 12 小时 59 分）
- 两种模式：工作+休息循环（双勾选）/ 仅工作后提醒（只勾选工作）；支持仅休息模式
- 1 秒心跳倒计时（墙钟目标时间，休眠期间按真实时间走，唤醒补提醒）
- 阶段完成提醒：置顶弹窗 + 托盘系统通知
- 配置持久化（AppConfig.json 新增节）+ 提醒台账（BreakReminderRecords.json）

## 三、关键逻辑说明

### 1. 计时引擎（Core\Servicers\Instances\BreakReminderServicer.cs）

- **计时方式**：`System.Timers.Timer(1000)` 心跳 + **墙钟目标时间**（`_phaseEndTime = DateTime.Now.AddMinutes(n)`）。每次 tick 计算 `剩余 = 目标时间 - 当前时间`，不累加心跳，因此无累积误差。
- **状态**：`_currentPhase`（Idle/Work/Break）、`_isRunning`、`_isPaused`、`_isSleeping`、`_wakeElapsedPending`，全部在 `lock(_syncRoot)` 内访问。
- **阶段切换**（`CompletePhase`）：工作完成 → 若启用了休息则进入休息；休息完成 → 若启用了工作则回到工作；否则停止（仅提醒模式），回到 Idle。
- **休眠策略**：订阅 `ISleepdiscover.SleepStatusChanged`；休眠期间 tick 直接 return（不完成阶段），唤醒时若目标时间已过则置 `_wakeElapsedPending`，下一个 tick 完成阶段并标记"休眠期间到期"（记录 + 弹窗文案区分）。
- **非法时长兜底**：`Math.Max(1, Math.Min(720, minutes))`——0/负数按 1 分钟、超大按 720 分钟（12 小时）。
- **参数校验**：工作与休息都未启用时 `Start` 抛 `InvalidOperationException`（UI 层先拦截并 toast）。
- **事件**：`PhaseChanged` / `RunningChanged` / `PhaseCompleted(phase, sleepElapsed)`，在 Timer 线程触发，UI 订阅方需自行 `Dispatcher` 调度（页面 VM 与通知服务均已处理）。

### 2. 表盘控件（UI\Controls\BreakReminderDial.cs）

- 继承 `FrameworkElement`，`OnRender` 自绘：透明背景矩形（**必须**，否则 WPF 命中测试穿透）、底环、60 刻度（每 5 分钟长刻度+数字）、选中弧线、端点圆点、中心大数字。
- 交互：`OnMouseLeftButtonDown` 捕获鼠标 → `OnMouseMove` 按角度换算分钟值 `round(atan2/6°) % 60`；点击中心 18% 半径区域不改变数值。
- 颜色：`TryFindResource` 读取主题键（ThemeBrush/StandardTextBrush/SubTextBrush/SettingPanelSpliteLineBrush），`IsEnabled=false` 时整体置灰；主题切换由页面 code-behind 订阅 `IThemeServicer.OnThemeChanged` 调 `InvalidateVisual()` 重绘。
- 数值 DP：`FrameworkPropertyMetadataOptions.AffectsRender | BindsTwoWayByDefault`，0-59 自动夹紧。

### 3. 页面与 VM

- 页面继承 `System.Windows.Controls.Page`，构造注入 VM（与现有页面一致）；VM 继承 `ModelBase`，`Dispose()` 中退订事件并停掉 UI 刷新 `DispatcherTimer`（PageContainer 返回导航时会调用）。
- 设置变更（复选框/表盘/小时）→ 若正在计时则 `Stop()` + toast 提示"设置已更改，计时已停止"→ `appConfig.Save()` 持久化。
- 开始前校验：至少勾选一项；启用的阶段总分钟 > 0；否则 `mainVM.Error(...)`。
- 倒计时显示：剩余 ≥1 小时显示 `h:mm:ss`，否则 `mm:ss`；UI 每 500ms 刷新一次剩余文本。

### 4. 提醒通知（UI\Servicers\BreakReminderNotifierServicer.cs）

- 应用启动时在 `App.xaml.cs OnStartup` 通过 `serviceProvider.GetService<BreakReminderNotifierServicer>()` 激活（构造中订阅 `PhaseCompleted`）。
- 触发：`Dispatcher.BeginInvoke` 到 UI 线程 → 托盘气泡（`StatusBarIconServicer.ShowBalloonTip`，后台也可见）+ 置顶弹窗（单实例复用，`UpdateContent` 更新文案）。
- 文案区分：工作完成 → "该休息了：工作阶段结束"；休息完成 → "休息结束：继续工作吧"；休眠到期有专门说明。

### 5. 提醒弹窗配色说明（重要坑）

`BreakReminderWindow` 是运行时 `new` 出来的独立窗口，实测其 XAML 中 `DynamicResource` 主题键（StandardBackgroundBrush 等）在部分场景解析失败导致黑底。**因此弹窗使用固定中性配色（白底 #FFFFFF、深灰文字、主题色图标在代码中 TryFindResource 读取）**，任何主题/资源状态下显示稳定。后续如需跟随主题，请先解决运行时窗口资源解析问题再改回 DynamicResource。

## 四、配置存储位置与格式

### 1. 设置（Data\AppConfig.json，与软件现有配置同一文件）

```json
"BreakReminder": {
  "IsWorkEnabled": true,
  "IsBreakEnabled": true,
  "WorkMinutes": 25,
  "BreakMinutes": 5
}
```

- 分钟数 = 小时 × 60 + 表盘分钟（例如 1 小时 30 分存 90）。
- 旧配置文件（无此节）由 `AppConfig.Load()` 的 `EnsureBreakReminderDefaults()` 自动补齐，不影响反序列化。
- 配置根目录：默认软件安装目录；用户在设置页指定自定义存储路径时随 `FileHelper` 一并迁移。

### 2. 台账（Data\BreakReminderRecords.json）

```json
[
  { "Time": "2026-08-12T13:21:28.7656216+08:00", "Phase": "Work", "Event": "Start", "DurationMinutes": 1, "Note": "开始计时" }
]
```

- `Event` 取值：Start / Complete / Finished / Pause / Resume / Reset / Sleep / WakeElapsed。
- 最多保留 200 条，超出移除最旧；每次事件即时写盘（JSON 数组整体序列化）。

## 六、回滚方式

1. **代码回滚**：本功能全部改动集中在"新增文件（10 个）+ 修改文件（8 个）"清单内，且均为**增量修改**（未删除/改写任何原有代码）。回滚 = 删除新增文件 + 撤销 8 个修改文件（git checkout 对应文件），即可回到改动前状态。
2. **配置回滚**：删除 `Data\AppConfig.json` 中的 `"BreakReminder": {...}` 节（或整体删除让软件重建默认配置）；删除 `Data\BreakReminderRecords.json` 即清除提醒台账。**不影响**原有 Links/General/Behavior/TimeLimit 数据。
3. **产物回滚**：使用改动前版本的 `guage.exe` 覆盖即可；新配置节对旧版本无影响（旧版本反序列化时忽略未知 JSON 字段——Newtonsoft 默认忽略缺失/多余属性）。
4. 建议：改动前先备份 `Data` 目录（含 AppConfig.json、data.db）。

## 七、已知边界与设计取舍

| 项 | 取舍说明 |
|----|----------|
| 休眠期间计时 | 按墙钟继续走（真实闹钟语义），唤醒补提醒并记录；如期望"暂停计时"需改 `Sleepdiscover_SleepStatusChanged` 逻辑 |
| 计时中改设置 | 停止计时并提示重新开始（保证可预期） |
| 运行时计时状态 | 不持久化（重启应用后回到空闲），仅设置与台账持久化 |
| 提醒强度 | 弹窗 + 托盘气泡，非强制（不做全屏锁定/强提醒，按需求范围外处理） |
| 音效 | 未加自定义音效（范围外），托盘气泡自带系统提示音 |
| 表盘上限 | 12 小时 59 分（小时 0-12 + 分钟 0-59） |
