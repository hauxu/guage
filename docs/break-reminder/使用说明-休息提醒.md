# 休息提醒（番茄钟）使用说明

> 适用版本：本次新增"休息提醒"功能的构建产物（guage.exe）

## 一、功能入口

启动软件后，左侧导航栏从上到下依次为：首页、统计、详细、分类、时长限制、**休息提醒**（新增，位于"时长限制"下方）、设置。

点击"休息提醒"进入功能页。

## 二、页面构成

页面从上到下分为四个区域：

| 区域 | 内容 |
|------|------|
| 标题区 | 页面标题与功能说明 |
| 工作时长卡片 | 工作时长复选框 + 圆形表盘（分钟 0-59）+ 小时步进器（0-12）+ 时长显示 |
| 休息时长卡片 | 休息时长复选框 + 圆形表盘（分钟 0-59）+ 小时步进器（0-12）+ 时长显示 |
| 计时控制卡 | 当前阶段（空闲/工作中/休息中）、剩余时间倒计时、模式说明、开始/暂停、重置按钮 |
| 提醒记录卡 | 最近 20 条提醒记录（时间、阶段、事件、备注） |

## 三、时长设置

### 表盘选择（类似谷歌时钟）

- 每个表盘是一圈 60 个刻度，每 5 分钟一个大刻度并标注数字（0/5/10…55）。
- **点击或按住拖动表盘上的刻度**即可选择分钟数，选中的刻度会高亮并显示蓝色弧线，表盘中心显示当前分钟数。
- 表盘只能表达 0-59 分钟。

### 一小时以上的时长

- 超过 60 分钟时，用卡片右侧的「小时」步进器（− / +）设置小时数，最大 12 小时。
- 总时长 = 小时 × 60 + 表盘分钟。例如 90 分钟 = 小时设为 1 + 表盘设为 30，显示为"1 小时 30 分钟"。
- 所有设置实时保存到本地配置，重启软件后仍然保留。

## 四、两种模式（复选框）

工作时长、休息时长前各有一个复选框，组合出两种使用模式：

| 勾选情况 | 模式 | 行为 |
|----------|------|------|
| 工作时长 + 休息时长都勾选 | **循环模式** | 工作 → 到点提醒"该休息了" → 自动进入休息 → 到点提醒"休息结束" → 自动回到工作，如此循环 |
| 仅勾选工作时长 | **仅提醒模式** | 只在工作结束后提醒一次"该休息了"，不进入休息阶段，计时停止 |
| 仅勾选休息时长 | 仅休息模式 | 从休息阶段开始计时，休息结束后提醒一次，计时停止 |
| 都不勾选 | 无法开始 | 点击"开始计时"会弹出红色提示"请至少勾选工作时长或休息时长" |

**注意**：计时过程中修改任何设置（勾选状态、表盘分钟、小时数），计时会停止，并提示"设置已更改，计时已停止，请重新开始"——这是刻意设计，保证行为可预期。

## 五、计时与提醒

1. 设置好时长后点击「开始计时」。
2. 计时过程中按钮变为「暂停」，可随时暂停/继续；「重置」立即停止并清零。
3. 阶段完成时：
   - **弹出提醒窗口**（置顶小窗，显示"该休息了"或"休息结束"及对应说明）；
   - **托盘系统通知**（屏幕右下角气泡，应用最小化/在后台时也能收到）；
   - 循环模式下自动切换到下一阶段并继续计时。
4. 提醒记录自动保存到本地 `Data\BreakReminderRecords.json`（最多保留 200 条），页面展示最近 20 条。

## 六、休眠/唤醒处理

- 系统休眠期间倒计时按真实时间继续走（像真实闹钟一样）；
- 唤醒后发现阶段已到期，会立即补发提醒，并在弹窗文案与记录中标注"休眠期间到期"；
- 避免计时偏差：倒计时基于墙钟目标时间计算，不依赖心跳累计。

## 七、配置存储

| 项目 | 位置 |
|------|------|
| 时长与模式设置 | `Data\AppConfig.json` 的 `BreakReminder` 节（与软件现有配置同一文件） |
| 提醒记录（台账） | `Data\BreakReminderRecords.json` |

## 八、常见问题

- **为什么开始不了？** 请至少勾选工作时长或休息时长，且启用的阶段总时长必须大于 0 分钟。
- **表盘能选 60 分钟吗？** 表盘范围 0-59 分钟；60 分钟 = 小时设为 1 + 表盘 0（显示"1 小时"）。
- **最小计时单位？** 1 分钟（便于测试；低于 1 分钟的非法输入会自动按 1 分钟处理）。
