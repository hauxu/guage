一、根因分析

#根因影响
1会话落库异步且无重试：应用切换时会话时长经 Task.Run 异步写库，数据库锁竞争/异常时写入失败仅记日志不重试——库值缺失 → 切页/刷新重新加载后显示回退到旧值（与切换前显示不一致）显示值 < 实际使用时长（跳变）
2详情页无实时刷新：概览页叠加「实时会话」显示，详情页仅显示库值且不订阅任何实时事件——同一应用在两处显示不同跨视图口径不一致
3前后台切换不立即补拉：窗口最小化/恢复或层级变化后，概览页定时器不保证立即刷新，展示值可能滞后于数据源恢复前台后显示陈旧

统一口径说明：所有统计视图显示值 = 数据库落库值 + 当前活动会话时长（同一算法 LiveDurationHelper）。会话结束时先落库（含重试），显示随库值更新——保证「显示」与「数据源」在任意时刻口径一致。
