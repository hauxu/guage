三、时长限制三模式增强

模式增强设置项
仅提示（Warn）可选 Windows 原生消息弹窗（更明显），默认应用内 Toast「使用 Windows 消息弹窗」复选框
倒计时关闭（CountdownKill）右上角置顶半透明数字倒计时（透明度可配、不挡内容）；连击 3 次隐藏（计时继续，到时照常结束应用）；倒计时归零结束目标进程全部实例，且当前会话内禁止再次启动（banned 进程被重启即再次结束）「右上角置顶悬浮倒计时」「透明度」「连击 3 次隐藏」「结束后禁止再次启动」
锁定遮罩（LockOverlay）全屏置顶遮罩需密码解锁：自定义密码（SHA256 存储）或随机 6 位数字字母混合密码（保证至少 1 数字+1 字母、排除易混淆字符）；随机密码可临时查看一次，查看后失效（按钮禁用）；解锁后可设再次锁定时间（默认 10 分钟）；锁定期间退出进程再打开立即重新锁定；密码连续错误不锁死「密码方式（随机/自定义）」「自定义密码」「解锁后再次锁定分钟数」「锁定期间退出重开立即锁定」

设置持久化：所有新字段写入 TimeLimitRuleModel/TimeLimitSettingsModel，随 AppConfig.json 自动持久化（含随机密码与查看状态），重启不丢失。

五、二次反馈 Bug 修复（2026-08-13 16:17）

反馈根因修复
关闭 guage 前台窗口后，仅提示不弹出应用默认 ShutdownMode=OnLastWindowClose：关闭主窗口 = 整个进程退出，时长限制服务随之停止改为 OnExplicitShutdown：关闭前台窗口 = 隐藏到托盘驻留（限制/统计继续运行），托盘菜单「退出」才真正退出进程；实测：关闭窗口后进程存活、窗口隐藏
「通过 Windows 消息弹窗提示」勾选自动取消设置保存路径 CloneRule 只拷贝 7 个旧字段，9 个新字段每次保存即丢失（重启后勾选消失）CloneRule 补齐 UseNativeMessageBox/ShowFloatingCountdown/CountdownOpacity/HideByTripleClick/BanRestart/PasswordMode/CustomPasswordHash/RelockMinutes/RelockAfterExit 全部字段
时长限制等页面操作后返回统计主页面，统计数字定格guage 自身前台时统计会话切换为 guage，但图表无 guage 条目 → 显示不更新（定格）；切到其他软件才恢复AppTimerServicer 忽略 guage 自身前台：返回主页面/设置页时长继续按上一应用累计，不再定格

单元测试新增 3 项断言（CloneRule 字段拷贝 ×2、忽略 guage ×1），全量 34/34 通过；Debug/Release 构建通过（16:17:15 / 16:17:23）。

五、验收自测清单（真机逐项）

  • 统计不卡：连续使用其他软件 ≥48h，观察概览页时长每秒递增，任何卡顿超过 1 秒不超过 1 次；最小化再恢复后显示立即正确；全屏游戏切换后统计继续
  • 资源：任务管理器观察内存（养护后应显著低于 120MB）；CPU 平均值 ≤5%（整体口径）
  • 消息弹窗：规则动作为「仅提示」并勾选「使用 Windows 消息弹窗」，到限时弹出 Windows 消息框且不阻塞其他操作
  • 置顶倒计时：动作为「倒计时关闭」，到限时右上角出现半透明倒计时；全屏下连击 3 次隐藏；归零后目标应用被结束，再次启动立即被结束（当前会话）
  • 锁定遮罩：动作为「锁定遮罩」，到限时全屏遮罩；随机密码可查看一次（再次查看按钮失效）；输入正确密码解锁；解锁后默认 10 分钟再次锁定；锁定期间杀进程重开立即锁定
  • 持久化：重启应用后规则设置/随机密码状态/统计时长不丢失
  • 异常：密码连续错误不锁死；快速连点无崩溃；系统时间调整不倒计时崩溃
