# 使用说明 · 时长限制三模式增强

本文档说明新增功能的使用方式。构建产物：`UI\bin\Debug\guage.exe` / `UI\bin\Release\guage.exe`。

## 入口
左侧导航 → 「时长限制」→ 添加应用（选择目标 exe）→ 设置「每日上限（分钟）」与「达到上限后」动作 → 展开规则卡片内的高级选项。

## 仅提示（动作=提醒）
- 勾选「使用 Windows 消息弹窗」：到限时弹出 Windows 原生消息框（更明显）；不勾选则使用应用内 Toast。
- 到限后当日不再重复提醒。

## 倒计时关闭（动作=倒计时关闭）
- 「右上角置顶悬浮倒计时」：勾选后到限时屏幕右上角出现半透明数字倒计时（置顶、不挡内容）；取消勾选则使用居中倒计时窗口。
- 「透明度」：0.1-0.95，数值越小越透明。
- 「连击 3 次隐藏倒计时」：在倒计时上快速连击 3 次（1.5 秒内）可隐藏显示；隐藏后计时继续，到时仍会结束应用。
- 「结束后禁止再次启动」：倒计时归零后结束目标应用全部进程，并在当前系统会话内持续阻止其再次启动（被禁进程重新打开会被立即结束）。
- 「延长 5 分钟 / 取消」按钮保留：可临时延长 5 分钟或取消本次执行。

## 锁定遮罩（动作=锁定遮罩）
- 「密码方式」：
  - 随机 6 位密码（默认）：系统生成 6 位数字字母混合密码（保证至少 1 数字+1 字母，排除 0/1/O/I/l 易混淆字符）。到限后遮罩上点击「临时查看随机密码」可查看一次；查看后按钮失效（无法再次查看）。密码输入正确后解锁。
  - 自定义密码：在「自定义密码」框输入（SHA256 存储，不存明文）。
- 「解锁后再次锁定（分钟）」：解锁后经过该分钟数再次锁定；0 = 不再自动锁定；默认 10。
- 「锁定期间退出重开立即锁定」：锁定状态下结束目标应用进程，再次打开时立即重新弹出锁定遮罩。
- 密码连续输入错误不会锁死，可继续尝试；解锁后随机密码作废（下次触发重新生成）。

## 数据与持久化
- 所有设置保存于 `UI\bin\Debug\Data\AppConfig.json`（TimeLimit 段），重启不丢失。
- 随机密码与「是否已查看」状态同样持久化。

## 常见问题
- 倒计时隐藏后如何恢复？：隐藏仅影响显示，到时自动执行结束应用；如需取消可在倒计时窗口隐藏前点击「取消」。
- 禁止重启持续多久？：当前系统会话内持续有效；重启软件后解除（会话级设计）。
- 消息弹窗与 Toast 区别？：消息弹窗为 Windows 原生 MessageBox（更醒目），Toast 为应用内轻提示。
